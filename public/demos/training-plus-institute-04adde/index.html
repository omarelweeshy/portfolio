Part 1 · Security finding

Casino spam is showing on trainingplusbh.com

While reviewing the public website (trainingplusbh.com) we found a block of Russian-language online-casino advertising injected into the page. Visitors and Google both see it, which harms trust and search ranking. This page summarises what we saw and how to fix it.

What visitors see

Outbound spam link

The block links visitors away to a gambling site. Shown defanged (not clickable) so nobody opens it by accident:

hxxps://casino-example[.]xyz/?ref=trainingplusbh

Illustrative domain: the exact target was not recorded during this review and must be confirmed from the page source during clean-up.

Likely causes

Typical for a CMS site such as WordPress; to be confirmed by a forensic check.

  • Outdated CMS core, plugins or theme with a known vulnerability.
  • Weak, reused or leaked admin / hosting / FTP passwords.
  • A “nulled” (pirated) theme or plugin carrying a backdoor.
  • Writable core files or insecure shared hosting letting malware persist.
  • Spam injected straight into the database (posts, widgets or options).

Clean-up and hardening steps

  1. Take a full backup and a separate forensic copy of files and database.
  2. Remove the injected content and backdoors from files and the database.
  3. Update CMS core, plugins and theme; delete anything unused or nulled.
  4. Rotate every credential: admin users, hosting, FTP/SFTP, database and API keys.
  5. Turn on two-factor authentication for all admin accounts.
  6. Add a web application firewall or security plugin with malware scanning.
  7. Tighten file permissions and disable file editing from the admin dashboard.
  8. Request a review in Google Search Console once the site is clean.
  9. Set up uptime and change monitoring with alerts to the owner.
