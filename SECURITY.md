# Security policy

This repository is a static personal portfolio site. It has no user accounts, forms that store data, or server-side secrets.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/omarelweeshy/portfolio/security/advisories/new)
or by email to omarelweshyy@gmail.com. Do not open a public issue.

I aim to reply within 7 days.

## Scope

- In scope: the code in this repository and the deployed site at https://omarelweeshy.vercel.app.
- Out of scope: the linked project demos, which have their own repositories and policies.
